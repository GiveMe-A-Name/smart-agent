# 排版与 HTML 实现要求

## 排版（默认样式，目的是让层级一眼可分）

- 层级：页面标题 > 引言 > 编号小节标题（0、1、2、3）> 正文。引言是带强调色左边框的独立区块，字号稍大于正文；小节之间用分隔线和明显的留白隔开；小节标题带编号、加粗，字号明显大于正文。每节第一句加粗。
- 使用者写的配置、示例和报错用带小标签的代码块或卡片展示，标签写明它是什么；报错用警示色。
- 折叠块是带边框的独立区块，与可见内容区分开；折叠标题用强调色、加粗，字号与正文相同，有明确的可点击样式；展开后标题与内容之间有分隔线，内容有内边距。
- 步骤示意用编号卡片列表，关键的那一步用颜色突出，并在卡片内用文字标注，不只靠颜色区分。
- diff 区块顶部写文件路径；删除行和新增行保留 -/+ 前缀，分别用浅红、浅绿背景。修改前后对照的表头写“修改前”“修改后”。
- 只用一种强调色和一种警示色；表格、卡片的字号不小于正文。

## HTML 实现要求

- 单文件 HTML，包含 DOCTYPE、html、head、body，设置简体中文语言、UTF-8 编码和 viewport。CSS 全部内嵌，不引用外部库、字体、图片或其他网络资源，也不发起网络请求。
- 用原生 `<details>`/`<summary>` 实现折叠，默认收起；点击、触摸或键盘都能展开。加一段内嵌脚本在打印前展开全部 `<details>`，使打印时展示完整内容；除此之外不使用 JavaScript，JavaScript 未执行时，默认可见内容和折叠标题仍然可读。
- 桌面和移动端都可读，正文宽度适中；代码块在移动端横向滚动或换行，不撑破页面；支持浅色与深色模式，并提供清晰的键盘焦点样式。
- 不使用 iframe、表单、eval、Function 或动态加载脚本；来自 PR 和代码的文本一律经 HTML 转义后写入。
