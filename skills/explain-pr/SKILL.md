name: explain-pr
description: "Briefly explain a PR or MR's problem, approach, and resulting changes. Use when the user wants a quick understanding of what a PR or MR does."
---

In your own words, help the user quickly understand the problem this PR aims to solve, its main approach, and the changes it brings.

Ground the explanation in the actual diff and the context needed to understand it. Distinguish this PR's changes from existing capabilities. Do not invent motivations or conclusions unsupported by the available evidence; state what you cannot confirm.

By default, give a brief explanation in the conversation, including only the background and details needed for understanding. Choose how to organize it. Expand on details in response to the user's follow-up questions.
